About VerifiedRecords

VerifiedRecords is an academic certificate verification web application developed by Siddhant Asati as an engineering college blockchain project. It provides an immediate, trustworthy digital alternative to slow, manual degree validation.

The Problem Addressed

Paper certificates and scanned PDFs are easy to forge or alter. Verifying qualifications through university registrar offices typically requires days or weeks of manual correspondence.

How Verification Works

Each certificate is issued with a unique Certificate ID. Verifiers enter the ID on the lookup page to instantly view authentic candidate, degree, and conferral details retrieved directly from institutional records.

Why Blockchain Is Used

Academic credentials should be permanent and tamper-resistant. In this project, Ethereum smart contracts were developed with Solidity to prototype immutable, auditable credential records that cannot be modified after issuance.

Current Implementation

Authorized staff sign in to record student certificates through the registrar portal, while public users can query and verify credentials in real time through a live Node.js REST API and MongoDB database.

Technologies Used

The application brings together web, database, and decentralized technologies across the stack:

HTML5 & CSS3
Semantic structure, tactile neumorphic controls, frosted glass panels, and responsive academic layouts.
JavaScript
Client-side state management, form validation, input handling, and asynchronous API calls.
Node.js & Express
REST API backend serving certificate lookups and administrative registration requests.
MongoDB
Persistent document store with indexed Certificate IDs for fast and reliable retrieval.
Firebase Auth
Administrative user sign-in, session monitoring, and protected dashboard access.
Solidity & Truffle
Smart contracts written to model decentralized, tamper-evident certificate records.
