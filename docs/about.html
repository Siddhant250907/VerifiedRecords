COLLEGE PROJECT OVERVIEW

About VerifiedRecords

VerifiedRecords is an academic credential verification project developed by Siddhant Asati as an engineering college project. It was created to explore how digital technologies can replace slow, manual certificate checking with an instant, trustworthy verification workflow.

The Problem It Addresses

Paper certificates and scanned PDFs are easy to forge or alter with basic image editors. When employers, graduate schools, or government agencies need to verify a student's degree, they often have to email or call the university registrar's office, waiting days or even weeks for manual confirmation.

How Verification Works

Each certificate is assigned a unique Certificate ID when issued. Anyone who needs to verify a degree—such as a recruiter or university admissions officer—can simply enter that ID on the public verification page. The system queries the university repository and displays authentic conferral details directly on screen in seconds.

Why Blockchain Is Relevant

In an ideal credential system, once an academic degree is granted, it should never be altered or revoked without full auditability. The project explores blockchain technology (using Ethereum smart contracts written in Solidity) because decentralized ledgers provide permanent, tamper-resistant record keeping without a single point of failure.

What the Project Currently Does

The platform currently provides a live, interactive web system: authorized staff can issue and store student certificates through a secure administrative portal, and the public can verify credentials in real time via our REST API connected to a live MongoDB database, with smart contract prototypes developed alongside it.

Technologies Used

This project integrates several web and database technologies across the frontend, backend, and decentralized layers:

HTML5 & Vanilla CSS3
Semantic structure, custom academic design tokens, and responsive light/dark themes.
Vanilla JavaScript
Client-side state management, form UX, input validation, and asynchronous API calls.
Node.js & Express
RESTful backend handling verification lookups and administrative certificate registration.
MongoDB
Persistent document store with case-insensitive indexing for Certificate IDs.
Firebase Authentication
User login, session monitoring, and route protection for registrar officers.
Solidity & Truffle
Smart contracts developed to model decentralized, tamper-proof credential storage.

Project Context

VerifiedRecords represents a hands-on learning journey in full-stack web development, REST API design, database modeling, and decentralized smart contract concepts. It is designed to demonstrate practical software engineering principles applied to real-world academic administration.
